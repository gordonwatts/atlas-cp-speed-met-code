# M26 linked scalar projection trial

The trial is based on the retained C source at `8c1c39f`. For each chunk and
original leaf, it can borrow the one-dimensional primitive NumPy content of an
untagged Awkward `ListOffsetArray`. Both arrays must have native dtype, aligned
contiguous full spans, and the leaf offsets must match the verified parent
container offsets. Each selected row is bounds checked before the vectorized
gather. Presence is true for a gathered row because this layout cannot carry
an option mask. NaN remains a numeric value. The gather and cast still use
the requested dtype.

Nested slot and length requests, option layouts, unknown types, slices, field
alignment mismatches and invalid row indices use the established generalized
projection. Empty location checks still follow the M21 path, including the
first shape, conversion and scatter check. The sampling projection is
independent of this trial.

The chunk cache holds references to original payload arrays and misses.
Successful classification does not flatten, copy, or cast whole leaves.
Each successful projection creates the output gather just as the established
path did. The diagnostic reports original bytes referenced and actual
cached dictionary size. Compare process peak RSS in the standard matched
production harness. Peak RSS of the differential checker includes both
outputs and does not represent the standalone worker.

After archiving the trial in its own snapshot, run its lightweight topology
tests and the separate original-input diagnostic with the pinned CPython 3.14
environment:

```bash
source="$snapshot/source/components/columnar"
runtime="$snapshot/runtime"
PYTHONPATH="$source" "$python314" -m unittest discover -s "$source/tests"
env LD_LIBRARY_PATH="$runtime/native" taskset -c 0 \
    "$python314" "$source/check_scalar_borrow.py" "$input" "$runtime" \
    "$fresh/linked-scalar-layout.json" --entries 2000
```

The diagnostic builds two sets of prepared transport columns from the same
unmodified original branch arrays. It forces the generalized path in one
set, checks identical field inventory, shapes, dtypes and numeric bits, and
requires selected electrons, photons, muons and taus. It verifies every
borrow by NumPy array identity and reports exact accepted and fallback calls.
Retain separate full independent A/C acceptance, clean installations, and
matched production timing before deciding whether to adopt the trial.
